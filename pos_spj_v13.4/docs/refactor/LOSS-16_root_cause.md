# LOSS-16 — Root cause

- Supported methods: Five Whys, Ishikawa, Pareto, Fault Tree and Direct Observation.
- One primary cause and zero or more distinct contributing causes per investigation.
- Canonical, idempotent application service with transactional outbox.
- Spanish desktop form backed by autocomplete selectors and a QueryService; no SQL in UI.
